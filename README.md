# Athaan-clock
A display clock that shows the times for Salah
Basically, It shows times for the next Salah, and little widgets like the date and time
, kabaa position, etc

## Materials

1. TFT 320mmx240mm screen
2. USB_C receptacle
3. ESP32-S3-Wroom-1
4. 4XAA battery holder
5. analog joystick with SW
6. 5 push switches
7. 1 power switch
8. UART debugger
9. 3d printed case to hold it all

## Passive Components
1. resistors
2. ceramic and radial capacitors
3. PNP transistor
4. voltage regulator
